##  Featured Projects

### 🛒 Merkato — Ethiopian E-Commerce Marketplace
> An Amazon-inspired marketplace built for Ethiopia

Full-stack e-commerce platform with a Node.js/Express backend, JWT authentication, bcrypt password hashing, email verification, and SQLite. Frontend features an Amazon-inspired layout with a navy/orange palette. Deployed on Render.

`Node.js` `Express` `SQLite` `JWT` `HTML` `Bootstrap` `JavaScript`

---

### 🤖 Freshman Hub 2026 — AASTU Telegram Bot
> Student onboarding bot for AASTU freshmen

A feature-rich Telegram bot for AASTU student orientation, running on Cloudflare Workers with Cloudflare D1 (SQLite at the edge). Features include registration flows, daily quiz streaks, leaderboards, and cron-triggered daily posts via the Grammy framework.

`Cloudflare Workers` `Cloudflare D1` `Grammy` `JavaScript` `Telegram Bot API`

---

### 📚 ExamMaster Pro — Exam Practice Application
> A single-file interactive exam prep tool

A self-contained HTML/JS/CSS exam practice app (~2,600+ lines) with IndexedDB persistence, KaTeX for math rendering, marked.js for Markdown, a custom "Vanta Prism" dark theme (neon green/ivory/black), and a full custom modal/dialog system. Built for AASTU-level English and subject exam practice.

`HTML` `CSS` `JavaScript` `IndexedDB` `KaTeX` `marked.js`

---

### 🔍 AI Text Tools — Humanizer & Detector
> Web tools for text analysis and humanization

Browser-based tools that detect AI-generated text and humanize writing. Used to refine real personal documents including scholarship application materials.

`HTML` `CSS` `JavaScript` `Anthropic API`
